# Build With Treez Launch Scorecard

## Release purpose

Reposition Build With Treez as an employer-first engineering portfolio while preserving its sacred-geometry identity and routing business-service inquiries to Codorus Web.

## Launch gates

### Creative

- [x] Hero and selected work pass the five-second and squint tests at 390px and 1440px.
- [x] Case studies vary in rhythm and do not repeat an identical card template.
- [x] WebGL remains a signature moment rather than ambient wallpaper.
- [x] Dark and light themes both feel intentionally art-directed.

### Commercial and professional

- [x] Target role, Security+ credential, and primary action are visible without animation.
- [x] Selected work uses explicit status and ownership labels.
- [x] No adoption, conversion, revenue, ranking, or security outcome is claimed without evidence.
- [x] Resume, portfolio, GitHub, LinkedIn, email, and employment dates agree.
- [x] Codorus Web is clearly secondary to the employment journey.

### Technical

- [x] Production build and lint pass.
- [x] Core content exists in initial HTML and remains usable without JavaScript or WebGL.
- [x] Keyboard navigation, focus visibility, headings, labels, errors, and 200 percent zoom are verified.
- [x] Reduced motion removes typed, scroll-reveal, particle, auto-rotation, and pulsing behavior.
- [x] 320px, 390px, tablet, and desktop layouts have no clipping or horizontal overflow.
- [x] Resume PDF is one page, selectable, link-preserving, and ATS extraction retains reading order.
- [x] Contact validation, honeypot, output encoding, request limits, throttling, failure recovery, and mailto fallback are verified.
- [x] Canonical metadata, Open Graph image, sitemap, robots, CSP, frame protection, referrer policy, and permissions policy are verified.

## Known measurement boundary

No recruiter conversion baseline is currently available. Lab checks are not field performance, and project release verification is not a business outcome.

## Post-launch review

At 30, 60, and 90 days, record:

- interviews or qualified conversations attributable to the portfolio;
- resume downloads and case-study engagement when privacy-respecting measurement is available;
- recurring recruiter questions or classification confusion;
- Ascension lead, search, and usability evidence approved for public use;
- field performance and contact-delivery failures.
