# Portal Keeper captures

Created November 3, 2026 from the original local game at `/play/portal-keeper`, build `-O14HTP41ICLITYBA3B1k` (source commit `63a3605`). These are native browser captures of the authored Three.js scene, not generated illustrations or third-party reference art.

- `observatory.png`: initial puzzle, mirror A selected.
- `awake.png`: aligned mirrors and matching lens, showing the live garden inside the portal.
- `garden.png`: the arrival scene after entering.

Each capture is 960 × 641 pixels. The browser used a 1024 × 900 viewport, reduced motion and a 640px scene height for this editorial framing. The full scene is preserved. UI chrome is excluded by capturing the scene element itself. PNG originals are retained; Next.js supplies responsive delivery formats. No image retouching or external assets were used.
